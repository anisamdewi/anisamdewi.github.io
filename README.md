# Anisa Mutiara Dewi — Portfolio

Personal portfolio website showcasing architectural engineering expertise and tenant fit-out project experience at AEON Mall Deltamas.

**Live Site:** [https://anisaarch.github.io](https://anisaarch.github.io)

## About

Architectural Engineering graduate with 5+ years of experience in retail construction, tenant fit-out supervision, and facility management. This portfolio highlights fit-out projects for 19 major brands across F&B and Retail categories.

## Features

- **Bilingual** — English / Bahasa Indonesia toggle
- **Responsive** — Works on desktop, tablet, and mobile
- **Project Gallery** — 40 photos across 19 tenant brands with lightbox
- **Category Filters** — Filter by F&B or Retail
- **Dark Theme** — Modern architecture-inspired design
- **Smooth Animations** — Scroll-triggered fade-ins
- **Zero Dependencies** — Pure HTML, CSS, and JavaScript

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox
- **JavaScript** — ES6+, IntersectionObserver API
- **Fonts** — [Poppins](https://fonts.google.com/specimen/Poppins) & [Inter](https://fonts.google.com/specimen/Inter)
- **Icons** — [Font Awesome 6](https://fontawesome.com/)
- **Deployment** — GitHub Pages
